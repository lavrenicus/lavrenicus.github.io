## Что есть сейчас

- Исходники тайлов коридора: `public/runner/assets/corridor/*.svg`

- Фон коридор **не использует текстуры**: `src/lib/corridor-gen.ts`

- PNG-тайлы **не сгенерированы**: SVG → PNG пропущено владельцем
  (2026-09-23); локальные конвертеры (`convert_*.py`) в коммит не входят.

## Если тема возобновится (отдельное решение владельца)

1. Починить конвертер — текущий путь сломан цепочкой: Pillow не открывает
   SVG → cairo-backend недоступен → svglib падает в `_shape_to_pdf_path`.
   Никаких фолбэков: выбрать и починить один механизм.
2. Сгенерировать PNG в `public/runner/assets/corridor/`.
3. Подключить к материалам `corridor-gen` в объёме, нужном фону;
   обе копии генератора правятся в одном изменении.
4. Showкейс-интеграция (`projects.ts`, галереи) — **вне скоупа фона**.

## Критерии (при возобновлении)

- PNG не превышают бюджет мобильного лейаута, TBT не растёт.
- Обе копии corridor-gen синхронизированы.
- `npm run lint` / `npm test` / `npm run build` — зелёные.
