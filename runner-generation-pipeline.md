# Runner background — пайплайн ассетов и текстур

**Версия 2.0 — переписан 2026-09-23 по решению владельца (Р2).**
Предыдущая редакция (v1, «ОДОБРИТЬ ПЛАН?») содержала корпоративный скоуп,
нерелевантный этому проекту (Kubernetes, Prometheus, ELK, S3/Lustre, GPU-бюджеты
$100k, ROI-метрики). Все эти пункты удалены как неприменимые к личному
статическому портфолио. Документ описывает **реальный** пайплайн фоновой
самоиграйки.

## Контекст и решения

- Фон секций = runner-платформер (todo §4.2, вариант **Б**), выбор изменён с
  варианта Д (desktopVillage) решением Илья, 2026-09-23; зафиксировано в todo.
- Визуальный спек — 3D-коридор по `public/runner3d-preview.html` (Р1): 7 тем,
  привязанных к секциям; Three.js подключается **через npm** (динамический
  `import()`), не через CDN.
- Реализация — компонент `src/components/RunnerBackground.tsx`
  (автопилот + тап-прыжок, пауза на hidden, статика при reduced-motion).

## Компоненты пайплайна

| Артефакт | Роль | Деплой |
| --- | --- | --- |
| `src/components/RunnerBackground.tsx` | фон-движок: сцена, темы, персонаж, автопилот | да (клиент, lazy) |
| `src/lib/corridor-gen.ts` | генератор коридора, **источник истины для сайта** (TS, npm three) | да (lazy-чанк) |
| `src/data/runnerThemes.ts` | 7 тем секций (порт из превью) | да (lazy-чанк) |
| `public/runner/corridor-gen.js` | копия генератора **только для автономного превью** (CDN importmap) | да (для превью) |
| `public/runner3d-preview.html` | визуальный спек и dev-страница (самодостаточная) | да (dev-инструмент) |
| `public/runner/assets/corridor/*.svg` | исходники текстур-тайлов коридора | да (исходники) |
| `convert_runner_textures.py`, `convert_svg_to_png.py` | локальные конвертеры — **не коммитятся** (этап 3 пропущен) | нет |
| `runner-corridor-texture-plan.md` | узкий план текстур | нет |
| `glb-preview.html`, `public/models/`, `models/` | dev-инструменты просмотра GLB/моделей | **нет** (см. ниже) |

**Синхронизация двух копий corridor-gen:** `src/lib/corridor-gen.ts` — рабочая
копия сайта; `public/runner/corridor-gen.js` — автономная копия превью (превью
не может импортировать код приложения). При изменении лейаута коридора править
обе копии в одном изменении; расхождение = ошибка ревью.

**Судьба dev-инструментов (решено 2026-09-23):** `public/models/`,
`public/glb-preview.html` и корневой `models/` — не используются сайтом и
исключены из деплоя через `.gitignore` (CI собирает артефакт из коммитов,
значит в GitHub Pages они не попадут, локально остаются для разработки).
`runner3d-preview.html` + `public/runner/corridor-gen.js` остаются в депле:
самодостаточные, крошечные, это спека Р1.

## Этапы

1. **Темы и генератор** — портированы в TS (готово, 2026-09-23).
2. **Движок фона** — `RunnerBackground`: сцена, автопилот, тап-прыжок,
   переключатель «живой фон» в футере, ошибки видимы в статусе (готово).
3. **Текстуры коридора** — **пропущен по распоряжению владельца
   (2026-09-23, «скипать SVG»)**: конвертация тайлов не выполнялась,
   PNG не сгенерированы, текстуры в `corridor-gen` не подключаются.
   Коридор рендерится геометрией — как в спеке `runner3d-preview.html`.
   SVG-исходники тайлов сохранены в `public/runner/assets/corridor/`.
4. **Синхронизация превью** — правка обеих копий генератора при изменениях.
5. **Верификация** — `npm run lint`, `npm run build`, `npm test`, Lighthouse
   (SEO ≥95, perf без регрессии), `graphify update`.

## Критерии приёмки

- Фон: 60fps на десктопе, DPR-кап ×2, пауза при `document.hidden`,
  статика при `prefers-reduced-motion: reduce`, тишина (никакого звука).
- Контент кликабелен всегда: фон — отдельный слой `z-0`, панель — `z-10+`.
- Три подгружается **только** при включённом фоне (динамический импорт).
- Ошибки (WebGL недоступен, неизвестная тема) — лог + видимый статус `bg: error`
  в футере; никаких фолбэк-движков и тихих no-op.
- Мёртвый вес в деплое отсутствует (см. таблицу).
