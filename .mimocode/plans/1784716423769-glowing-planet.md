# Миграция портфолио: HTML → Next.js + TypeScript + Tailwind CSS

## Контекст

Текущий проект — статичное портфолио на чистом HTML/CSS/JS (3 файла, ~570 строк). Нужно перевести на Next.js (App Router) с TypeScript и Tailwind CSS, сохранив текущий дизайн и добавив интерактивность + секцию игр. Деплой остаётся на GitHub Pages.

## Выбор стека (подтверждено)
- **Фреймворк:** Next.js (App Router) + TypeScript
- **Стили:** Tailwind CSS
- **Деплой:** GitHub Pages (статический экспорт)

## Шаги реализации

### Шаг 1: Резервное копирование и инициализация

1. Переименовать оригинальные файлы (`.old` суффикс) чтобы `create-next-app` не перезаписал
2. Перенести `demos/` и `Raw/` обратно после инициализации
3. Запустить `npx create-next-app@latest . --typescript --tailwind --eslint --app --src-dir --import-alias "@/*" --use-npm`

**Создаются:** `package.json`, `tsconfig.json`, `next.config.ts`, `tailwind.config.ts`, `postcss.config.mjs`, `src/app/` скелет

### Шаг 2: Конфигурация `next.config.ts`

```ts
import type { NextConfig } from "next";
const nextConfig: NextConfig = {
  output: "export",           // статический экспорт для GitHub Pages
  images: { unoptimized: true }, // нет сервера оптимизации
  trailingSlash: true,        // GitHub Pages нужен /page/
};
export default nextConfig;
```

> `basePath` не нужен — репо `lavrenicus.github.io` (user site).

### Шаг 3: Конфигурация `tailwind.config.ts`

Расширить тему кастомными цветами из текущего CSS:
- `bg: #060a12`, `bg-alt: #0a0f1a`, `panel: #0d1420`
- `border: #1c2a3d`, `border-strong: #2c4260`
- `text: #dce6f2`, `text-dim: #7f93ac`
- `accent: #3fa9ff`, `accent-dim: #1a5c96`
- Шрифты: `display: Space Grotesk`, `mono: JetBrains Mono`

### Шаг 4: `src/app/globals.css`

- Tailwind directives (`@tailwind base/components/utilities`)
- `html { scroll-behavior: smooth }`
- `body { @apply bg-bg text-text font-display antialiased }`
- Кастомные стили: `.grid-overlay` (фиксированная сетка), `@keyframes blink`, `.cursor-blink`

### Шаг 5: `src/app/layout.tsx` — шрифты через `next/font/google`

- `Space_Grotesk` → CSS variable `--font-display`
- `JetBrains_Mono` → CSS variable `--font-mono`
- Метаданные: title, description

### Шаг 6: Типы и данные

**`src/types/index.ts`**: интерфейсы `Project`, `TechSkill`, `NavLink`, `SocialLink`

**`src/data/projects.ts`**: массивы с данными из оригинального HTML:
- 4 проекта (PixiAndDestroy, BAM History, Campus Navigator, Logic Rails)
- 10 навыков
- 6 ссылок навигации
- 4 соцсети

### Шаг 7: Компоненты (10 штук)

| Компонент | Описание | Клиентский? |
|-----------|----------|-------------|
| `GridOverlay` | Декоративная сетка (aria-hidden) | Нет |
| `Header` | Sticky нав + мобильный бургер (useState) | Да |
| `Hero` | Hero секция с CTA и терминалом | Нет |
| `ProjectCard` | Одна карточка проекта | Нет |
| `Projects` | Сетка из ProjectCard | Нет |
| `Games` | Табы + iframe (useState, фильтрует проекты с demoKey) | Да |
| `TechGrid` | Сетка навыков | Нет |
| `About` | О себе | Нет |
| `Links` | Соцсети | Нет |
| `Footer` | Подвал | Нет |

**Ключевые решения:**
- Секция "Demos" переименована в "Games" (по запросу пользователя)
- Навигация: `#demos` → `#games`
- Данные проектов централизованы в `data/projects.ts` — добавление нового проекта = 1 объект
- Мобильное меню: бургер-кнопка с анимацией (CSS transitions через Tailwind)
- Games: `useState` + `key={active}` для iframe — переключение пересоздаёт iframe

## Верификация

1. `npm run dev` → открыть `localhost:3000` → все секции на месте, тёмная тема, шрифты, grid overlay
2. Клик по навигации → smooth scroll работает
3. Табы Games → iframe src меняется
4. Бургер на мобильном (< 768px) → меню открывается/закрывается
5. `npm run build` → папка `out/` создана, `out/index.html` существует
6. `npx serve out` → статика работает автономно
7. Карточки проектов стекаются вертикально на узких экранах
8. Hero текст масштабируется через `clamp()`
